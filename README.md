# Система бронирования столиков для ресторана "Berins"

Проект состоит из двух частей:

- **Бэкенд** на Django + Django REST Framework. Отвечает за API, базу данных и админку.
- **Фронтенд** на React + Material-UI. Там пользователи выбирают столики и бронируют.

## Технологии

- Python 3.12 / Django 6.0
- Django REST Framework
- SQLite (для простоты)
- React 18
- Material-UI (MUI)
- Axios для запросов
- Notistack для уведомлений
- date-fns для работы с датами
